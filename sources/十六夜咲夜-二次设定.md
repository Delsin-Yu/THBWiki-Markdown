## 静态设定

### PAD长
解释
: 绰号，装备
来源
: 在萃梦想里的立绘的乳量比ZUN绘大以及女仆（maid）与PAD音近的缘故，所以有使用了PAD的二设和PAD长的绰号，并经由各种恶搞同人而流传开来，但实际上萃梦想立绘比ZUN绘乳量大的角色不止她一个（紫和美铃也是），毕竟ZUN绘中只有小町与牛崎润美是巨乳（绯想天和非想天则的新增角色立绘乳量比咲夜大的也只有小町）

- 因此也有不少人相信萃梦想的立绘与咲夜的真正乳量是一致的，认为她拥有傲人的巨乳（完美的女仆身材当然是完美的）。
- 有以此为题的MMD《女仆长，PAD长》。
- 在2020年的日本是已经近乎失传的上古老梗。


### 服饰
解释
: 因身穿迷你裙女仆装的缘故，被认为拥有一双美腿，同人里也常常穿着吊带袜或是裤袜。
来源
: 初次登场时。

## 动态设定

### 和[八意永琳](./八意永琳.md)的关系
解释
: 在二次创作中有时被设定为月人（在永琳叛逃时被杀的月面使者之一，幸而未死，跨越时间追缉永琳；又或者偷取了永琳的月时计之后连续时间加速逃到未来，但因为无法承受高速时间而失去记忆等）。 　
来源
: 永夜抄中与八意永琳的谜样对话

### 和[红美铃](./红美铃.md)的关系
解释
: 喜欢欺负红美铃，不过也有同人里设定与她有暧昧关系。
来源
: 
  
东方非想天则美铃线结局
  

### 和[蕾米莉亚](./蕾米莉亚·斯卡蕾特.md)的关系
解释
: 萝莉控，特别是对蕾米，经常妄想蕾米至流鼻血(赤红的忠诚心)。

- 永夜抄中的可选自机组合，梦幻的红魔组，一般简称为红魔组。寿命论高发组合
- 绝不仅仅是主仆关系，无论是在一设还是二设中，两人都有着深深的信赖和羁绊。 
  - 永夜抄中有这样的对话：




```
蕾米莉亚：对了，咲夜不想要不老不死吗？这样就能和我一直在一起了。咲夜：我一生都是会死的人类哦。放心，只要还活着就会一直陪着大小姐。——[红魔组ex](./游戏对话-东方永夜抄-梦幻的红魔组_ExStory.md)```


## 其他流行设定

### 《MUGEN》中的咲夜
解释
: /
来源
: Mugen中红魔馆五位原有主要角色中尚未出嫁的两人之一，不过最近跟月姬格斗的七夜志贵来往密切，经常有七夜潜入红魔馆的剧情出现。 两人接近于官配，组成“二十三夜”或是“七咲”组。但七夜从月姬中的妻管严发展成mugen中的万人迷……跟辉夜（夜之名）、天子等都似乎有关系……不过双方都有披着彼此的皮的马甲，连七夜·斯卡雷特都有了。

- 拥有神最上的God Cho马甲（GOD长，捏自PAD长），以及S咲夜（息废人氏的CC蛟下属，全开防御面准论外）
- 因为在妖妖梦中被蓝说“看起来像是狗”所以有了犬属性。在mugen中表现为小巧可爱萌到要死的PADOG（犬咲夜）。蕾米则是猫。


### DIO的女儿
解释
: 属性
来源
: 咲夜拥有操纵时间程度的能力，拥有符卡幻世「The World」，因此被认为是JOJO的奇妙冒险中的大反派，拥有停止时间的替身“The World”的迪奥·布兰度的女儿。

- 有不少二次创作，包括图片、漫画、视频。
- 在绯想天和非想天则里咲夜的其中一个配色就是DIO的配色，她的22b/c「完美女仆」发动时会摆出一个JoJo立。
- ZUN是Jo厨，红魔乡及后续作品里使用过很多JoJo里的捏他。


### 犬咲夜
解释
: 属性
来源
: 在[妖妖梦对话](./游戏对话-东方妖妖梦-十六夜咲夜_ExStory.md#Extra_Stage)中蓝说她“看起来像是狗”所以有了犬属性。独立的犬咲夜形象相关作品也很多。

- 其中最有代表性[ANGELTYPE](./ROYALCAT.md)のネジ氏创作的形象，写作「いぬさくや」（全平假名）。MUGEN马甲和毛绒玩具都采用了此形象。
- 也因此与犬走椛组成CP。椛：都说了我是狼啦！


### 魔法少女咲夜（マジカル☆さくやちゃんスター）
解释
: 绰号、梗
来源
: 在妖妖梦中使用意义不明的带星星图案的子机，与某魔法少女形象不谋而合。[^cite_note-1]

- 咲夜的魔法能力只是能不用火柴点燃壁炉等方便女仆工作的程度，不适用于实战。
- 尽管没有提及，不过一般认为她是到了红魔馆后才学会魔法的，而教她的人是帕秋莉·诺蕾姬。 
- 也是新作中除雾雨魔理沙以外唯一一个能使用魔法的人类。


### 十六夜宵夜
解释
: 输入法错误会把咲夜打成宵夜

### 腹黑
解释
: 在二次创作动画《梦想夏乡》中的配音是田中理惠，原来她是17岁的腹黑女仆

### 乳咲
解释
: 在商业二次创作手游[东方Lost Word](./东方LostWord.md)中，咲夜的强度非常低，甚至达到了垫底级别，所以只要是谈到咲夜都是在乳咲，甚至还有外号"咲神" ~~，咲夜厨不用生气，因为这都是神永恒の温柔~~ MV咲夜的强度推翻了本条定律，真正意义上的“咲神”

## 梗

### 哇，喜羊羊！
来源
: [#小李出城 哇，不知不觉已经是第46次来到城里，果然是大开眼界！（抖音短视频）](https://v.douyin.com/exebA4R/)
时间
: 2021年6月7日-至今（截至2021年8月）
解释
: 一位短视频制作者“小李没有飞刀”（抖音id：KahongTV）制作的系列搞笑短视频，其中一期对着路边痛车上的咲夜图案喊“哇，喜羊羊！”。[^cite_note-2]  
甚至当天下午就传到了车主那里，然后车主也玩起了这个梗。

- 车主为[SDG工作室-牧师](https://space.bilibili.com/186168)

[^cite_note-1]: 最早或可追溯到红魔乡中，咲夜确实有一瞬间放出了火焰形态的弹幕，但占据大部分屏幕的仍然是飞刀，并不是太引人注意，并且往后的正作中咲夜也没有再使用过该种弹幕。
[^cite_note-2]: 为防真的有人不知道，喜羊羊是知名国产儿童动画形象，系动画《喜羊羊与灰太狼》的主角。
