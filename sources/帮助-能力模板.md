帮助文档

本页是THBWiki的[编辑帮助文档](./分类-帮助文档.md)  
Wiki内的公式人物中，有能力模板的，均使用模板来生成人物能力。
  
  
能力模板参见分类**[能力模板](./分类-能力模板.md)**，内容目录参见**[能力模板目录](./能力模板目录.md)**。
  
  
以博丽灵梦的能力为例：
  
  
**中文名**  

```
{{博丽灵梦能力|1|红魔乡1}} ```


- 飞翔于空中程度的能力


```
{{博丽灵梦能力|1|妖妖梦}} ```


- 主要拥有飞翔于空中程度的能力

  
  
**日文名**  

```
{{博丽灵梦能力|2|红魔乡1}} ```


- 空を飛ぶ程度の能力


```
{{博丽灵梦能力|2|妖妖梦}} ```


- 主に空を飛ぶ程度の能力

  
  

具体人物的可使用参数请点击映射方案 (未找到链接)并输入"对应人物能力/中文"或"对应人物能力/日文"查看
