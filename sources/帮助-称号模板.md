帮助文档

本页是THBWiki的[编辑帮助文档](./分类-帮助文档.md)  
Wiki内的公式人物中，有称号模板的，均使用模板来生成人物称号。
  
  
称号模板参见分类**[称号模板](./分类-称号模板.md)**，内容目录参见**[称号模板目录](./称号模板目录.md)**。
  
  
以博丽灵梦的称号为例：
  
  
**中文名**  

```
{{博丽灵梦称号|1|红魔乡}} ```


- 博丽神社的巫女小姐


```
{{博丽灵梦称号|1|红魔乡Omake}} ```


- 永远之巫女

  
  
**日文名**  

```
{{博丽灵梦称号|2|红魔乡}} ```


- 博麗神社の巫女さん


```
{{博丽灵梦称号|2|红魔乡Omake}} ```


- 永遠の巫女

  
  

具体人物的可使用参数请点击映射方案 (未找到链接)并输入"对应人物称号/中文"或"对应人物称号/日文"查看
