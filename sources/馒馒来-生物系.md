# 简介
  
生物系馒馒来是亚文化东方Project 的分支亚文化[馒馒来](./馒馒来.md)的创作派系。细分派系有爱派和虐派。
其在[馒馒来大讲堂](https://bbs.nyasama.com/forum.php?mod=viewthread&tid=66762)中被描述为：  
“将馒馒来当作生物设定和创作的得名2chan”、“处于混沌系和东方系之间，所以有时会对两边作出一些连动”、“拥有生物构造，脱离东方所形成的体系”。
  
  
关于馒馒来生物系虐派创作详见[馒馒来/生物系/馒馒来虐待](./馒馒来-生物系-馒馒来虐待.md)、[馒馒来/生物系/设定](./馒馒来-生物系-设定.md)。
