## 可信度
  
**同人作品的资料应当来自准确的来源，不同来源之间出现冲突的话可以参考一下可信度列表判断：**  

1. 制作方官网对BK的修正
2. BK、随碟小册子、光盘上印刷的文字
3. 制作方官网、制作方上传的试听视频
4. 制作方相关人士的推特、脸书等
5. 其他资料网站

  
不过有时候千言万语也不如听一遍实在，要是官方确实没写某些信息，但你相当确定你能听出来，那写上也无妨。
  

## 辅助编写工具
  
**辅助编写工具包括输入提示、自动插入模板、模板关联运算和音频属性读取工具。**  
  
**几乎所有需要打字的地方都会有输入提示，上至制作方、展会、风格、售价，下至编曲、演唱、作词、原曲，甚至更复杂的重复曲汇入，都有各种各样的提示。**  

对于大部分项目来说，输入提示都只是建议，可以不按建议来输入。  
**但唯独原曲和展会必须点击输入提示中相应的项目，即便你已经输入了全称，也必须点击输入提示来将文字转换成模板，<big> 否<big> 则<big> 会<big> 爆<big> 炸</big></big></big></big></big>。**  

没有正确填写的原曲和展会分别会出现在 [分类:没有使用音乐名模板的页面‎](./分类-没有使用音乐名模板的页面.md) 和 [分类:没有使用展会名模板的页面](./分类-没有使用展会名模板的页面.md) 里。
  

- 所有出自东方（西方以及部分相关作品）的原曲都有模板，没有使用音乐名模板的页面分类内不应有任何页面。
- 目前部分小型展会及东方参与度不高的展会会缺少相应的模板，无可避免会出现在没有使用展会名模板的页面分类中，管理员有空时便会修理。

## 流程
  
**这里给出标准的编辑流程：**  

1. 首先要知道你要写哪个专辑，可以从[此页面](./待编写的同人作品词条.md)中寻找，也可以是全新的专辑。
2. 编辑社团页面，添加新专辑（如果已经有就不用了）。
3. 提交编辑，点击新专辑的链接，创建新专辑页面。
4. 选择并插入页面格式模板。
5. 编写 同人专辑信息 模板内的资料，比如名称、制作方、售价、官网页面等，具体编写格式请参看文本框底部的输入提示文字。
6. 编写 专辑曲目列表 模板内的资料，可以使用 [音频属性读取工具](http://tool.thwiki.cc/tags/) 或在输入提示辅助下手动输入。
7. 编写 专辑人员列表 模板内的资料，按照输入提示文字的指示输入即可。
8. 写上Cover Artwork、Illustration、Artwork Design、Mastering、PV制作、Special Thanks等杂项参与人员。
9. 如果专辑有官方试听（包括官网、通贩页面、视频/音频网站中由制作方发布的），可以在试听段落填写相应的内容，具体编写格式请参看文本框底部的输入提示文字。没有试听的话请删掉试听段落
10. 查错。
11. 提交编辑，点击封面链接上传封面图片，注意后缀名（.jpg、.png等）要相同，封面图片必须（上传时在摘要框内）写上{{封面图片}}，上传时忘了写可以在图片页面按编辑重新写上。
12. 检视整个页面，再次查错。
13. 完成。

## 词条各项参数详细说明
  
本部分内容由寒夕残（寒夕残 (未找到链接)（讨论 (未找到链接)） 2016年4月4日 (一) 21:01 (CST)）编写，关于同人音乐相关词条编写如有任何问题均可直接联系本人（联系方式见个人页面）。   
  
  
上述同人音乐词条规范记叙了基本的填写方法。   

以下则提供词条中常用的各项参数的具体说明，以及一些填写建议和技巧。   

内容均出自个人填写经验，比较细碎繁杂，并非规范和要求，仅供参考。   
  

### 专辑信息
封面
: 本项一般无需修改，会自动匹配名称与**词条名**相同的图片文件（即使不是jpg格式也能识别，但建议填写正确的图片格式）；
名称
: 本项可填写完整的专辑名称，不必与词条名相同。由于词条名称对字符编码有所限制，部分符号无法使用。而此处则可填写大部分符号；
译名
: 多数专辑没有译名。可以把专辑名中用片假字表示的英文单词写成英文形式；
制作方
: 多数社团都可以根据输入的字符显示提示，但最近才编写词条的社团不会显示在提示列表中；
: 此外如填写带有重定向的社团名称（如幽閉サテライト），均会显示为重定向后的名称（幽闭星光）；
首发日期
: 此项通常只用于非展会发布的专辑（比如网络发布的免费下载），但如果展会一项填写的是**还没有创建词条的小型展会模板**，或**没有创建模板的展会名称**，则需要填写此项，并将本参数置于“展会”之前。这样才能正常显示日期；
展会
: 必须选择模板。如发现没有模板或有模板但没有展会对应词条，可自行创建相应内容或联系本人编写；
编号
: 比较难找的一项内容。一般在专辑的封底或侧边扫图上可以找到，有时虎穴的通贩页面也会提供封底的缩略图，非新发布的专辑还可以在[vgmdb.net](http://vgmdb.net/)上查找；
类型
: 虽然这一项只提供单一参数的提示，但只要使用中文逗号分隔即可正常显示多个参数；
: 其中**全长**，**EP**，**单曲**三项形容的是不同长度的专辑类型，一般含有5首以上的不同曲目即为“全长”，一首歌曲（可能另含一首伴奏或附赠曲）为“单曲”，EP介于两者之间（详细分类可参考Wikipedia）。如果专辑属于EP或单曲类型，制作方通常都会在网站或专辑名称中加以说明（如幽闭星光的专辑在官网上就按照全长，EP和单曲分别排号）；
: 如选择**原声集**，则需在“类型”下面添加“| 原声集 =”这一参数，并在其后填写本专辑是哪部作品的原声集；
: **印象集**使用较少。一般可以用于仿ZUN曲风格的原创专辑；
: **合作**可用于多个社团参与制作的专辑，也可用于某一社团通过募集形式收录众多投稿作品的专辑形式；
风格类型
: 这一项仅说明大致的曲风，不需太计较准确的风格分类。比如“古典”，“新世纪交响”，“钢琴独奏”，“室内乐”均可归为**古典**，“爱尔兰”，“和风”，“二胡”均可归为**民族**等等；
: 注意这里的**硬核**应指电音曲中的Hardcore，而非金属/摇滚乐；
会场售价
: 没什么要说的，有时候宣传的动态/网站/视频上没写可以尝试搜索品书或者现场摊位图片；
通贩售价
: 注意请填写不含税的价格，正常通贩网站会标明价格是含税（税込み）还是不含税（有些网站直接在商品价格后面有“+税”）的。
: 如果是含税的需要手动计算一下，现时点消费税是10%，所以`不含税价格=四舍五入（含税价格/1.1）`；
官网页面
: 一般填写特设页网址，或该专辑在官网的信息页网址。如没有时可填写通贩页面或试听页面
: 另外注意部分社团（如[うんちく商事](./うんちく商事.md)）会将新发布的专辑信息暂时存放在某一页面，展会结束后移动到新址。在填写时请用“官网补充”参数予以说明。
: 如发现旧专辑页面中的网址失效，请勿直接删除，因为原网址仍可通过查找历史记录的方式访问。请用“官网补充”参数说明网址现已失效。
特定选材
: 这一项默认是不添加的，但如果满足参数说明中的条件（如全专辑的原曲均出自同一作）则应手动添加；

### Staff
专辑人员列表模板
: 本模板的“替换”一项可以自动收集下方曲目列表中所有的“编曲/再编曲”，“演唱/伴唱/和声/配音”和“作词”，然后在词条中分类显示人名和参与创作的曲目。如在人名后添加了“= 社团名”或“= 链接 社团名”，则在人名后追加显示社团名的站内词条链接或外部链接；
: 这一模板一般只在参与创作的人员较多，且所属曲目明确时使用。如果整张专辑由一人完成全部工作，或社团人员分别参与了哪些曲目的信息不明，则建议仿照画师/设计师的形式从特设页摘录staff信息；

### 曲目列表/同人曲目信息
  
同人曲目信息中的参数项目众多，这里只写需要说明的内容。
  
原专辑/原名称/社团
: 默认情况下不会显示这三项参数，只有通过输入曲名查找并添加名称相似曲目时，会在载入曲目信息的同时自动添加这三项内容，作为当前曲目的出处；如果确认自己想要填写的曲目来自其他专辑，但该专辑尚未编写词条，也可手动添加这三项内容；
: “社团”一项如果与上面填写的“制作方”内容相同，则不会显示；
: 维基的查找相似曲名功能会识别专辑发布时间，在选项上悬停时可以看到；
时间
: 如果使用载入的旧曲信息，请注意核实曲目时长没有改变。因为有些曲目在remix或重制之后会和之前有所不同。
再编曲
: 即remix；当一首曲目作为出处被载入时，“再编曲”一项中的人名会归并入“编曲”之中；
伴唱/和声
: **和声**为曲中没有具体歌词的人声哼鸣；而**伴唱**则指除主唱之外，负责次要声部的歌手；
曲风
: 这里可供选择的类型与专辑风格类型列表相同。一般无需单独填写。如果特设页明确给出了每首曲目的风格（如[dat file records](./dat_file_records.md)的很多专辑），则建议将准确内容填写至**备注**一项；

### 评论
  
这一项填写的内容不明。我个人最近喜欢将特设页或通贩页的专辑自我介绍摘录于此，仅供参考。
  

### 下载
  
不应该写下载，本WIKI定位为资料站而不是资源站。
  

## 其他细节问题
  
以下细节问题多出于**保持词条格式一致性**，或**方便用户检索**的目的而提出，并非强制要求；   
  

- 如非特殊需要，请将日文字符特有的反向波浪线“〜”改写为正向波浪线“～”（可用全角）；
- 如非特殊需要，请将半角日文假名和全角英文字符（如ｱｲｳｴｵ，Ａａ等）改写为一般输入格式；
