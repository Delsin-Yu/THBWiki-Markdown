## 一设资料

### 东方刚欲异闻
  
（在本节提及了有关旧血池地狱的信息，此处仅为摘要，具体内容请查看[东方刚欲异闻](./游戏对话-东方刚欲异闻-芙兰朵露·斯卡蕾特.md#Ending_A)）  
  

```
旧血池地狱。 将大罪人的体力、精力一同削弱， 最终连该大罪人都一并吸收的被诅咒的设施。 因其即便是在旧地狱中也未免过于阴森可怖， 希望来工作的鬼越来越少，成了无法管理的状态。 血池地狱被用业火焚烧，隐藏了起来。 然后，当地狱本身迎来搬迁之时 血池地狱彻底被人们遗忘了。 不，是因为连鬼都厌弃它的邪恶，故意将它遗忘了。 ```


## 相关设定

- 位于[旧地狱](./旧地狱.md)，[灼热地狱遗址](./灼热地狱遗址.md)的地下深处，为原本的血池地狱的遗迹。
- 其设立的目的是削弱和吸收罪人的体力、精力，乃至于其本身。
- 后逐渐失去管理，被用业火焚烧后隐藏，在[旧地狱](./旧地狱.md)搬迁后彻底被遗忘。
- 血池地狱中存在着近乎无限的「被诅咒的血液」，为[刚欲异闻](./东方刚欲异闻.md)中「石油」的真身，蕴含着生命的「恐惧、悲欢、憎恶、怨恨」。
- [刚欲异闻](./东方刚欲异闻.md)中旧血池地狱被唤醒，「石油」满溢而出，形成场景「石油之海」。
- 异变后，[饕餮尤魔](./饕餮尤魔.md)和[摩多罗隐岐奈](./摩多罗隐岐奈.md)成为了旧血池地狱的共同管理者。


## 结构与造型

#### 设定点

- 在[刚欲异闻](./东方刚欲异闻.md)中，此场景最初以「石油之海」显现。
- 场景整体十分昏暗，下方满是混沌黏稠的「石油」，不时有大团的「石油」液块向上方浮动。
- 显露出「旧血池地狱」的真实面貌后，场景整体变得明亮鲜红。
- 场景下方为血液的海洋，不时有血液以手爪的形状向上方喷涌而出。
